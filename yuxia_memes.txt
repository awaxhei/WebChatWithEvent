# 尤夏「最近飘过的梗」清单
#
# 用法：一行一个，写她这个年纪（大一、网上冲浪、打游戏、养猫的人）会认得的东西。
# 以 # 开头的行是注释，不会进提示词。改完重启服务（App 的话重装/重启）生效。
#
# 注意：这里是「她认得」，不是「她要说」——提示词里已经写明，她只在对方先抛时接，
# 而且一次只接一个。所以宁少勿多，也不要塞只有你懂的内部笑话（那些她从对话里就能记）。
#
# 梗会过时。觉得哪条已经没人说了，直接删掉或换掉。
